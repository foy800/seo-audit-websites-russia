# SEO-аудит сайтов (РФ: Яндекс + Google)

Когда просят проверить сайт на SEO, объяснить, почему он не индексируется, или сделать аудит перед запуском:

1. Прочитай [SKILL.md](SKILL.md): там чеклист, эдж-кейсы вайбкод-сайтов, специфика РФ, приоритизация и шаблон отчёта.
2. Запусти автоматическую проверку (нужен Python 3.8+ и доступ в интернет, сторонние пакеты не нужны):
   ```
   python scripts/quick_check.py https://example.ru --pages 10
   ```
3. Всё, что скрипт не проверяет (Яндекс Вебмастер, Google Search Console, скорость из РФ, беклинки, юридические требования), пометь как «проверить вручную».
4. Выдай отчёт по шаблону из SKILL.md. Каждую находку подтверждай фактом: ответом сервера, строкой robots.txt или фрагментом HTML.

Правила: тексты для клиентов только по-русски («вопросы и ответы», а не FAQ); позиции и сроки не обещать; к чужим сайтам не делать массовых запросов (главная, robots.txt, sitemap и до ~20 страниц).
