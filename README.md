# seo-audit — SEO-аудит сайтов для РФ (Яндекс + Google)

Скилл для [Claude Code](https://claude.com/claude-code): проверяет сайт на SEO и объясняет, почему поисковики его не видят. Основан на чеклисте для вайбкод-сайтов и дополнен спецификой российского рынка: Яндекс, доступность из РФ, 152-ФЗ, VK и Telegram, ИИ-поиск.

## Для кого

- владельцы сайтов и предприниматели, которые сделали сайт через ИИ (Lovable, Bolt, v0, Cursor, Claude Code) и не видят его в поиске;
- SEO-специалисты и маркетологи, которым нужен быстрый технический аудит перед глубокой работой;
- разработчики, которые хотят проверить сайт перед запуском.

## Что умеет

**Автоматическая проверка** (`scripts/quick_check.py`, только стандартная библиотека Python 3, без установки пакетов):

- доступность главной, редиректы http → https и www / без www, срок SSL-сертификата;
- как сайт отвечает Googlebot и YandexBot (ловит Cloudflare-челлендж и WAF);
- `noindex` в мета-тегах и заголовке `X-Robots-Tag`, `canonical` (в том числе на localhost и `*.vercel.app`);
- `title`, `description`, `H1`, иерархия заголовков, `alt`, `lang`, `viewport`;
- Open Graph, фавикон, Schema.org (JSON-LD);
- `robots.txt` (включая `Disallow: /`, `Sitemap`, правила для ИИ-ботов), `sitemap.xml`, `llms.txt`;
- soft 404, hash-роутинг `/#/`, пустой HTML у CSR-сайтов;
- наличие Яндекс Метрики и метатегов подтверждения Вебмастера и Search Console;
- внешние ресурсы, которые могут не грузиться из РФ (Google Fonts, GA, reCAPTCHA, виджеты Meta);
- битые страницы и дубли `title` / `description` по выборке до N страниц.

**Инструкция для Claude** (`SKILL.md`): полный чеклист, таблица эдж-кейсов вайбкодеров, приоритизация находок (🔴 критично, 🟠 важно, 🟡 желательно), шаблон отчёта и план правок на 2 недели.

## Что добавлено для РФ

- Яндекс Вебмастер и Метрика, региональность, `Clean-param`, `<meta name="yandex">`, IndexNow, более слабый JS-рендер Яндекса (SSR / SSG важнее);
- локальное SEO: Яндекс Бизнес, Яндекс Карты, 2ГИС, единые название, адрес, телефон;
- коммерческие факторы: контакты, реквизиты, цены, доставка, отзывы;
- доступность из РФ: скорость, блокировки РКН, зарубежные CDN, домены `.рф`;
- юридическое: политика персональных данных, cookie, 152-ФЗ, маркировка рекламы;
- превью ссылок в VK, Telegram, WhatsApp;
- ИИ-поиск: Алиса, Яндекс Нейро, YandexGPT, GigaChat, `llms.txt`, роботы нейросетей;
- семантика по Wordstat, региональные посадочные, каннибализация запросов.

## Типичные проблемы вайбкод-сайтов, которые проверяются

| Проблема | Последствие |
|---|---|
| Cloudflare-челлендж блокирует ботов | поисковик получает 403 / 503 и не индексирует сайт |
| CSR: в HTML пустой `<div id="root">` | бот видит пустую страницу |
| Hash-роутинг `/#/about` | внутренние страницы не индексируются |
| SPA отдаёт 200 на любой URL | мусорные страницы в индексе (soft 404) |
| `canonical` / `og:url` на localhost из dev-сборки | сайт указывает поисковику на несуществующий адрес |
| `noindex` с Vercel-превью попал на боевой домен | сайт исключён из выдачи |
| Гео-блок режет трафик из США | Googlebot не может зайти на сайт |

## Установка

Клонируйте репозиторий в папку скиллов Claude Code:

```bash
git clone https://github.com/foy800/seo-audit-websites-russia.git ~/.claude/skills/seo-audit
```

Для Windows путь: `C:\Users\<имя>\.claude\skills\seo-audit`. После этого скилл подхватывается автоматически.

## Как использовать в Claude и ChatGPT

**Claude Code** (терминал или приложение): установка выше, дальше просто просите проверить сайт. Скрипт запускается сам.

**Claude.ai (чат в браузере или приложении):**
1. Скачайте репозиторий как ZIP (Code → Download ZIP) или заархивируйте папку `seo-audit` так, чтобы `SKILL.md` лежал внутри папки.
2. Settings → Capabilities → Skills → Upload skill, выберите архив (нужен платный тариф с включённым выполнением кода).
3. В чате напишите: «проверь сайт example.ru на SEO». Если у чата нет доступа в интернет, он не запустит скрипт сам. Тогда запустите `quick_check.py` у себя и пришлите вывод, Claude составит отчёт по шаблону.

**ChatGPT:**
1. Создайте свой GPT (Explore GPTs → Create) или Project.
2. В поле Instructions вставьте содержимое `SKILL.md` без блока в начале файла между `---`.
3. В Knowledge загрузите `scripts/quick_check.py` и `README.md`.
4. Встроенный Python в ChatGPT работает без выхода в интернет, поэтому скрипт на чужой сайт он не запустит. Рабочая схема: запустите скрипт у себя (`python quick_check.py https://example.ru`), вставьте вывод в чат и попросите «составь отчёт по шаблону и план правок». Для проверки вручную можно также прислать исходный код страницы (Ctrl+U) и содержимое `robots.txt`.

**Codex CLI, Cursor и другие агенты:** положите текст `SKILL.md` в `AGENTS.md` (или правила проекта) и оставьте `scripts/quick_check.py` в репозитории. Агент с доступом к терминалу запустит скрипт сам.

## Использование

В Claude Code напишите, например:

- «проверь сайт example.ru на SEO»;
- «почему мой сайт не индексируется в Яндексе»;
- «сделай SEO-аудит перед запуском».

Или запустите проверку вручную:

```bash
python ~/.claude/skills/seo-audit/scripts/quick_check.py https://example.ru --pages 10
```

Пример вывода:

```
❌ robots.txt отсутствует или отдаёт HTML — статус 404
⚠️ Нет canonical [главная]
✅ Googlebot получает 200
✅ SSL-сертификат валиден — осталось 57 дн.

Итого: ❌ 1  ⚠️ 1  ✅ 2
```

## Ограничения

Скрипт видит только публичный сайт. Не проверяются автоматически: данные Яндекс Вебмастера и Google Search Console, реальная скорость из РФ, обратные ссылки, позиции, региональная привязка, юридические требования. В отчёте такие пункты помечаются «проверить вручную». Скилл не даёт юридических гарантий и не обещает позиций в поиске.
