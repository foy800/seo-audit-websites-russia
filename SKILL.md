# SEO-аудит сайта (Яндекс + Google, РФ)

Цель: найти причины, по которым поисковики не видят или плохо ранжируют сайт, и выдать приоритизированный список правок. Не выдумывай находки: каждый пункт подтверждай фактом (ответ сервера, фрагмент HTML, строка robots.txt).

## Порядок работы

1. Запусти быструю автопроверку (stdlib Python, без зависимостей):
   ```
   python ~/.claude/skills/seo-audit/scripts/quick_check.py https://example.ru
   ```
   Скрипт проверяет блоки 1–4 и часть 5–7 и печатает JSON-подобный отчёт ✅/❌/⚠️. Он смотрит сырой HTML (то, что видит бот без JS) — это важно для SPA.
2. Если сайт — исходники в репозитории, дополнительно прочитай код: роутер, `index.html`, конфиги (`vercel.json`, `next.config.*`, `netlify.toml`, `nginx.conf`, `.env*`), генерацию sitemap/robots.
3. То, что скрипт не может проверить (Вебмастер, Search Console, Метрика, скорость из РФ, ссылки), пометь как «нужен доступ / проверить вручную».
4. Выдай отчёт по шаблону внизу.

## Чеклист (база)

**1. Индексация и доступ**
- `sitemap.xml` есть, отдаёт 200, указан в `robots.txt`, URL каноничные и живые (≤ 50 000 URL / файл).
- `robots.txt` отдаёт 200, не закрывает `/` и важные разделы (`Disallow: /` — красный флаг), не блокирует CSS/JS.
- Нет `noindex`: ни `<meta name="robots">`, ни `<meta name="yandex" content="noindex">`, ни заголовка `X-Robots-Tag`.
- `canonical` на каждой странице: абсолютный URL, самореферентный, на боевой домен (не localhost, не `*.vercel.app`).
- Главная доступна по одному варианту: http→https, www/без www — один 301 на основной, без цепочек редиректов.

**2. Мета и структура страницы**
- `<title>` уникален, 30–65 символов, ключ ближе к началу, бренд в конце.
- `<meta name="description">` уникален, 70–160 символов, продаёт клик (Яндекс и Google могут подставлять свой).
- Ровно один `<h1>`, иерархия H1→H2→H3 без перескоков, H1 ≠ дубль title слово в слово.
- `alt` у значимых картинок; декоративные — `alt=""`.
- `lang` у `<html>` (`ru`), корректная кодировка UTF-8, `viewport`.
- Чистые URL (slug): латиница через дефис или транслит, без `?id=123`, `_`, заглавных; кириллические slug допустимы, но проверь, что не ломаются в соцсетях.

**3. Разметка и превью**
- Schema.org (JSON-LD): `Organization`/`LocalBusiness`, `BreadcrumbList`, `Product`/`Service`/`Article`, `FAQPage` где есть вопросы-ответы. Валидность: валидатор микроразметки Яндекса и Rich Results Test.
- Open Graph: `og:title`, `og:description`, `og:image` (абсолютный URL, ~1200×630, отдаётся 200), `og:url`, `og:type`, `og:locale=ru_RU`. Проверь превью для VK и Telegram.
- Фавикон: `favicon.ico` + `<link rel="icon">` (Яндекс показывает его в выдаче; квадрат, кратный 16, желательно ≥ 120×120 для Яндекса).

**4. Ссылки**
- Внутренняя перелинковка: нет «сирот», важные страницы ≤ 3 кликов от главной, осмысленные анкоры, не только JS-клики по `onclick`.
- Битые ссылки (4xx/5xx), внутренние и исходящие; ссылки на `localhost`/превью-домены.
- Внешние ссылки (беклинки): качество и анкоры, нет ссылочного спама; проверка через Вебмастер/Ahrefs/Серпстат.

**5. Скорость и мобильность**
- Картинки сжаты, WebP/AVIF, `width/height`, `loading="lazy"` ниже первого экрана.
- Core Web Vitals: LCP < 2.5 c, INP < 200 мс, CLS < 0.1 (PageSpeed Insights, замеры из РФ).
- Адаптив: `viewport`, нет горизонтального скролла, тап-зоны ≥ 44 px.
- HTTPS принудительно, валидный сертификат (срок, цепочка, нет mixed content), HSTS желателен.

**6. Подтверждение и мониторинг**
- Сайт подтверждён в Google Search Console **и** в Яндекс Вебмастере; sitemap отправлен в оба.
- Установлена Яндекс Метрика (и/или GA4), цели настроены.

## Эдж-кейсы вайбкодеров (проверяй обязательно)

| Проблема | Как проверить | Лечение |
|---|---|---|
| Cloudflare-челлендж не пускает ботов | `curl -A "Googlebot"` / `-A "YandexBot"` возвращает 403/503 или «Just a moment» | WAF-правило для проверенных ботов, отключить Under Attack / Bot Fight для краулеров |
| CSR-рендер: бот видит пустой `<div id="root">` | Сырой HTML (`curl`) без текста и H1 | SSR/SSG/prerender (Next.js, Astro, Nuxt, prerender.io). **Яндекс JS-рендерит заметно хуже Google** — для РФ это критично |
| Hash-роутинг `/#/about` | В ссылках есть `#/` | History API (`BrowserRouter`), отдельные URL |
| Soft 404: SPA отдаёт 200 на любой URL | `curl -I /несуществующая-страница-xyz` → 200 | Настоящий 404 статус + страница 404 |
| canonical на localhost из dev-сборки | `canonical`/`og:url`/sitemap содержат `localhost` или `*.vercel.app` | Задать `SITE_URL` в production env, пересобрать |
| noindex на Vercel-превью попал в прод | `X-Robots-Tag: noindex` в заголовках, `vercel.json` headers | Убрать заголовок для production, проверить env |
| Гео-блок: Googlebot ходит из США | Сайт режет трафик по гео/IP | Не блокировать США для известных ботов (верифицировать по rDNS) |

## Специфика РФ (добавлено сверх базового чеклиста)

**Яндекс**
- **Яндекс Вебмастер**: подтверждение прав, раздел «Индексирование» (страницы в поиске / исключённые и причины), «Диагностика» (ошибки сайта), «Качество сайта» и ИКС, «Региональность» — привязка региона для коммерческих запросов.
- **Яндекс Метрика**: счётчик установлен на всех страницах, Вебвизор/карты кликов для поведенческих; поведенческие факторы (отказы, глубина, время) влияют на ранжирование.
- В `robots.txt` для Яндекса: `User-agent: Yandex` отдельным блоком; директива `Host` устарела, зеркало задаётся 301-редиректом; `Clean-param` для UTM/служебных параметров (дубли).
- Закрытие фрагментов от индексации: `<meta name="yandex" content="noindex">` или `<!--noindex-->…<!--/noindex-->` (только для Яндекса); `nofollow` на ссылки — отдельно.
- Яндекс игнорирует `meta keywords`; в сниппете может использовать `description` или текст страницы.
- **IndexNow** поддерживается Яндексом — быстрый пинг об изменениях.
- Яндекс хуже Google исполняет JS и медленнее переиндексирует — SSR/SSG приоритетнее.
- Яндекс Бизнес (Справочник) + Яндекс Карты, 2ГИС, Google Business Profile: карточки организации, единые NAP (название, адрес, телефон), отзывы, режим работы — для локального SEO обязательны.
- Турбо-страницы Яндекс закрыл — если в коде остались `turbo`-RSS/разметка, это мусор.

**Коммерческие факторы** (интернет-магазины и услуги): телефон и адрес в шапке/подвале, реквизиты (ИНН/ОГРН), страница «Контакты» с картой, цены, условия оплаты и доставки, возврат, отзывы, кнопки мессенджеров, онлайн-запись/корзина.

**Доступность из РФ**
- Сайт открывается из РФ без VPN и быстро: хостинг/CDN в РФ или с узлами в РФ, TTFB < 600 мс. Зарубежные CDN, Cloudflare, Vercel, Netlify иногда тормозят или блокируются.
- Внешние ресурсы, которые могут не грузиться: Google Fonts, Google Analytics/Tag Manager, reCAPTCHA, YouTube-встройки, часть зарубежных CDN, Facebook/Instagram-виджеты (Meta — запрещена в РФ, не вставлять её виджеты и пиксели). Замени на локальные шрифты, Метрику, SmartCaptcha, VK Видео/RuTube.
- Проверь, что домен/IP не в реестре блокировок РКН (check.rkn.gov.ru) и не режется хостером.
- Домены `.ru`/`.рф`: у `.рф` проверь punycode в canonical/sitemap/og:url (единый вид), возраст и история домена, не штрафован/не под фильтром.
- SSL: сертификаты Let's Encrypt/Sectigo работают; если сертификат зарубежного УЦ может быть отозван — рассмотреть российского УЦ (учитывать, что часть браузеров его не доверяет).

**Юридические требования (влияют на доверие и риски)**
- Политика обработки персональных данных, согласие в формах (152-ФЗ), баннер cookie; персональные данные граждан РФ хранить на серверах в РФ.
- Реквизиты владельца сайта; для рекламы — маркировка (ERID) и регистрация в ОРД.

**Соцсети и мессенджеры РФ**
- Превью при отправке в VK, Telegram, WhatsApp, Max: og-теги + `og:image` ≥ 600 px; для VK можно задать `vk:image`. Лёгкий вес картинки (< 1 МБ).
- Соцсети, пригодные для ссылочного профиля и узнаваемости: VK, Telegram-канал, Дзен, VK Видео, RuTube, Яндекс Карты/Бизнес.

**ИИ-поиск (Алиса, Яндекс Нейро, YandexGPT, GigaChat, ChatGPT и др.)**
- В `robots.txt` не закрыты `YandexAdditional`, `YandexBot`, при желании — `GPTBot`, `ClaudeBot`, `PerplexityBot`, `OAI-SearchBot`, `GigaChat`‑боты; решение о допуске принимает владелец.
- Файл `llms.txt` в корне — краткое описание сайта и ключевых страниц.
- Контент в формате «вопрос — ответ», списки, таблицы, структурированная разметка повышают шанс цитирования в нейро-ответах.

**Контент и семантика под РФ**
- Семантическое ядро по Wordstat (Яндекс) — частотности и региональность; кластеризация по выдаче; один кластер — одна страница.
- Геозависимые запросы («купить … в Барнауле»): отдельные посадочные под регион/город, регион в title/H1 и контактах.
- Каннибализация: несколько страниц на один запрос → объединить / развести интент.
- Тексты: не переспам, E-E-A-T (автор, опыт, сроки обновления, источники), уникальность, глубина ответа на интент.
- Ссылочное: покупные ссылки с бирж могут вредить; ориентируйся на естественные упоминания, каталоги отраслевые, СМИ.

## Приоритизация

- 🔴 **Критично** (сайт не индексируется / недоступен ботам): noindex, `Disallow: /`, Cloudflare/гео-блок, пустой CSR-HTML, soft 404, canonical на localhost, нет HTTPS, недоступность из РФ.
- 🟠 **Важно** (теряется трафик): нет/дубли title, description, H1; нет sitemap; битые ссылки; медленная загрузка; нет мобильной версии; не подтверждён Вебмастер/GSC.
- 🟡 **Желательно**: разметка, og-превью, alt, перелинковка, фавикон, llms.txt, IndexNow.

## Правила

- В текстах для клиентов — только русские термины: «вопросы и ответы» вместо FAQ, «страницы, приводящие заказы» вместо Money Page, «пробелы в контенте» вместо Content Gap. Англицизмы без перевода не использовать.
- Не обещай позиции и сроки; не давай юридических гарантий (по 152-ФЗ — «проверьте с юристом»).
- Не делай массовых запросов к чужим сайтам: достаточно главной, robots.txt, sitemap и выборки до ~20 страниц.
- Правки в коде клиента вноси только по запросу; сначала покажи список находок.
